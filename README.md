# engineer-career-map

未経験からエンジニアへの転職を目指す人向けの学習資料です。
「どんな仕事があるか」から「転職までの道のり」まで、全体像を地図のように見せます。

## 構成

| 章 | タイトル | 答える問い | ファイル |
|---|---|---|---|
| 1 | プログラマーの仕事 | どんな仕事があるのか？ | [chapter1.html](chapter1.html) |
| 2 | Webサービスができるまで | どういう流れで作るのか？ | 作成予定 |
| 3 | 必要な知識 | 何を身につけるのか？ | 作成予定 |
| 4 | 転職までの道のり | どう進めばいいのか？ | 作成予定 |

- 1章はWebに限らず、職種や働き方を紹介します。
- 2〜4章は、Webを例に説明します。

## 見方

`chapter1.html` をブラウザで開きます。`index.html` を開くと1章に移動します。
